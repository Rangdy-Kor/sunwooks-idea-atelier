# Windows NEO

---

개인적으로 원하는 Windows의 이상향.

## 디자인

---

**Noto Font 통합**:

- 시스템 기본 폰트가 일관성 있는 다국어 지원을 위해 Noto 시리즈로 통합된다.
- 기존 레거시 폰트 (맑은 고딕, Segoe UI 등)은 폴백 폰트로 내장되나, 더 이상 기본 폰트로 사용되지 않는다.
- 시스템 및 인터페이스에는 Noto Sans, 워드프로세서 등 문서에는 Noto Serif, 터미널과 IDE / 에디터에는 Noto Sans Mono가 기본값으로 사용된다. [^1]
  **LucidType**:
- 디스플레이 폰트 가독성 향상 기술이 고해상도 모니터에서의 효과를 증폭 시키기 위해서 차세대 LucidType으로 교체된다.
- 기존 서브 픽셀 렌더링 방식인 ClearType이 FHD 이상의 해상도에서 유의미한 가독성 향상 효과를 보이지 못하였다.
- Noto Font와 ClearType의 궁합 또한 긍정적인 평가를 받고 있다 말하기 어려웠다.
- 때문에 LucidType은 차세대 그레이스케일 안티 앨리어싱 기술을 사용하며, 사용자의 모니터 해상도를 감지하여 동적으로 강도가 조절된다.
- HD 이하의 해상도에서는 여전히 ClearType이 자동으로 적용된다.
  **Bubble UI**:
- 기존 평면적인 UI가 사용자의 만족도를 충족하지 못한다는 점을 해결하기 위해 Fluent Design에 새로운 디자인 형식인 Bubble UI가 추가된다.
- Bubbld UI는 다른 인터페이스 위에 레이어 식으로 더해져 입체감과 시인성을 더한 원형 / 알약 형태의 UI이다.
- 적용 범위와 사례는 아래와 같다.
  - **창 조절 버튼**: 기존 제목 표시줄에 통합되어 있던 창 조절 버튼의 위치가 창 내부로 이동함과 동시에, 원형 플로팅 Bubble UI로 변경된다. 호버 / 클릭 액션 등 특정 트리거 없이 기존과 같이 창을 조절할 수 있다. 시각적 형태만이 원형으로 변경되었을 뿐, 상호작용 범위는 기존과 동일한 넓이의 정사각형 범위이다.
  - **작업 표시줄**: 화면 하단 전체를 차지했던 작업 표시줄이 플로팅 알약 형태로 변화한다. 검색 상자와 시스템 트레이, 위젯 버튼은 작업 표시줄에서 독립하며, 예외적으로 바탕화면 보기 막대는 기존의 최우측 하단 자리를 유지한다. 창을 최대화하거나 타일링할 시 애니메이션과 함께 좌우로 확장되며 기존의 작업 표시줄 바처럼 변한다. 이러한 효과는 최대화 및 타일링 시 작업 표시줄이 가리지 못하는 양쪽 공백에 비쳐지는 바탕화면에 시각적 불안정성을 느끼는 사용자들이 많다는 점에서 고안되었다. 이는 _개인 설정_ => _작업 표시줄_ => _창의 최대화 / 타일링 시 작업 표시줄 확장_ 옵션에서 비활성화 할 수 있다.
  - **시스템 트레이**: 작업 표시줄에 통합되어 있던 시스템 트레이가 화면 상단으로 이동한다. 시계 트레이와 날짜 트레이, 빠른 설정창, 입력기 전환, 백그라운드 앱 보기 토글은 우측 상단에 위치하게 되며, 알림 센터와 배터리 표시 아이콘만 별도로 좌측 상단으로 이동한다. 시스템 트레이는 완전히 투명한 배경을 지녔기에 바탕화면이 비쳐보이나, 배경색에 따라 자동으로 텍스트 색상이 검정 - 회색 - 흰색으로 3단 조절되기에 시인성을 확보할 수 있다. 각 시스템 트레이 모듈은 독립된 버튼으로 간주되기에 개별적으로 클릭 및 호버 이벤트를 호출할 수 있다.
  - **앱 내부 버튼**: 창의 배경과 동화된 형태였던 WinUI 3의 기본 버튼에도 Bubble UI가 적용된다. 별도의 레거시 버튼 UI 또한 사용할 수 있다.
    **Mist 재질**:
- Bubble UI와 유사하게 기존 재질들이 사용자의 만족도를 충분히 충족시키지 못한다는 판단 하에 Fluent Design에 새로운 재질인 Mist가 추가된다.
- Mist는 현재 모바일 앱 등지에서 자주 발견할 수 있는 실시간 블러 효과이며, 바로 아랫층의 요소를 비추는 고밀도의 실시간 블러가 입혀진다.
- 때문에 바탕화면만을 비추는 Mica / Mica Alt와 플라스틱 아크릴 판을 모방한 Acrylic과는 차별화된다.
- 실시간 블러 효과의 특성 상 기존 3가지 재질보다는 GPU 등의 시스템 리소스 사용량이 많기에, Mist는 Bubble UI가 적용된 요소에 한정되어 사용된다.
- Mist 재질은 _개인 설정_ => _색_ =>_실시간 블러 효과_ 옵션을 통해 비활성화 할 수 있다.

## 기능성

---

**Windows Copilot Agent**:

- 최근 파일 검색 등의 단순한 작업만을 수행할 수 있던 Windows Copilot에 본격적인 AI Agent 기능이 추가된다.
- Windows Copilot Agent의 엔진은 OpenClaw[^2]를 기반으로 하며, Windows에 맞게 커스텀되었다.
- Windows Copilot이라는 앱에 종속되기에 일부 작업 시 관리자 권한의 허용을 사용자로부터 요구 받으나, 이는 Windows Copilot 자체를 관리자 권한으로 실행하여 해결할 수 있다.
- 만약 기기에 NPU가 탑재되어 있다면 로컬 기기에서 Copilot이 실행되며, NPU가 없거나 최소 요구 사항을 충족하지 못한다면 기기 내 GPU, 그마저도 전력 소모량 등의 효율성이 떨어진다면 OpenAI의 클라우드 컴퓨팅 자원 (주로 MS Azure)을 사용하게 된다.
  **Windows Launcher**:
- 작업 표시줄의 시작 버튼 우측에 위치했던 검색 상자가 화면 하단에서 사라지며, 대신 Windows Launcher라는 이름으로 재탄생 한다.
- Windows Launcher는 PowerToys Run 모듈의 소스 코드를 기반으로 한다.
- Windows Copilot Chat / Agent 호출, 그리고 Direct Console 기능이 통합되어 있다. Direct Console은 별도의 터미널 창을 열지 않고도 Windows Launcher에서 즉석으로 명령어의 출력 결과를 보여주는 기능을 뜻한다.
- PowerToys Run과 달리 별도의 접두사 없이도 정규 표현식과 Copilot의 문맥 인식 기능을 통해 수식 / 명령어, 혹은 자연어만으로 자동으로 명령을 인식하여 알맞은 기능을 수행한다.
- Windows Launcher는 앱 실행 중이 아닐 시 화면 상단 가운데게 작은 알약 형태의 레이블로 존재한다. 마우스가 호버될 시 애니메이션과 함께 양옆으로 확장되며, 바 형태의 긴 상자로 변한다. 상자를 클릭하면 Mist 효과가 적용된 하단 연관 결과가 PowerToys Run과 유사하게 나타난다.
- 레이블이 화면을 중앙의 공간을 차지하는 것을 방지하기 위해 앱의 최대화 / 타일링 시 화면 상단의 제스처 막대 형태로 변환한다. 해당 막대를 클릭하거나 끌어 내려 Windows Launcher를 호출할 수 있다.
- 이외에도 Alt+Space 단축키로 접근성 높은 경로를 통해 호출할 수 있다. 본래 Alt+Space에 할당되어있던 마우스가 보급되기 이전에 사용되었던 사용률이 낮은 단축키인 창 제어 호출 메뉴 기능은 제거된다.

[^1]: Noto Sans Mono는 일반적인 [Google Fonts](https://fonts.google.com) 웹에서는 라틴 문자 버전만을 찾아볼 수 있으나, 공식 GitHub 저장소에서는 CJK 등 각종 다국어 버전이 배포되고 있다.

[^2]: [OpenClaw](https://github.com/openclaw/openclaw)는 이메일 작성, 코딩, 오피스 업무 등 실무 상의 연쇄적인 의사결정 작업까지 가능하도록 설계된 AI Agent 프로젝트이다. GitHub에서 역대 최단 기간에 가장 많은 스타 (현재 37만 스타)를 받으며 React의 기록을 넘어선 프로젝트로 알려져 있다. 현재 OpenClaw의 개발자 피터 스타인버거는 OpenAI로 영입된 상태이며,  MS Copilot의 내부 모델 공급사인 OpenAI이기에 OpenClaw의 기술이 제공될 가능성이 충분하다 판단하였다.
