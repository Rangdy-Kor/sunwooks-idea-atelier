# Rootrion Font Family --- 2026-05-08 16.01

---

Rootrion은 Root + Criterion의 합성어이다.

**굵기**:

- Static:
  - Thin
  - Extra Light
  - Semi Light
  - Regular
  - Medium
  - Semi Bold
  - Extra Bold
  - Heavy
- Variable

**종류**:

- Sans:
  - Root Sans: 일반 산세리프
  - Root Round Sans: 끝이 둥근 산세리프
  - Root Straight Sans: 모든 선이 곧게 뻗은 산세리프
  - Root Old Sans: 옛 문자 형태의 산세리프
    Root Sans Mono: 코딩용 고정폭 산세리프
  - Root Sans Pixel: 레트로 스타일 픽셀 형태 벡터 산세리프
- Serif:
  - Root Serif: 일반 세리프
  - Root Serif Display: 간결화된 획의 디스플레이 최적화 세리프
  - Root Old Serif: 옛 문자 형태의 세리프
  - Root Serif Eco: 미세한 구멍을 뚫은 잉크 절약형 세리프
