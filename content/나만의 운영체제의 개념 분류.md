# 나만의 운영체제의 개념 분류

---

**개발 환경**:

- **운영체제 개발 환경**:
  - **부트로더**: Assembly, C
  - **커널**: C, Rust
  - **드라이버**: Rust
  - **인터페이스**: Rust (Slint), CSS / TSX (React)
- **생태계 개발 환경**:
  - **스타일 / 테마**: CSS
  - **스크립트 / 모듈**: TS / WASM
  - **애플리케이션**: CSS / TSX (React), Rust
  - **프로그램**: CSS / TSX (React), Rust

**구성 요소** (Component):

- **스니펫** (Snippet): 무설치형.
  - **스타일** (Style): 비실행형. 외형의 변화.
  - **스크립트** (Script): 실행형. 기능의 추가.
- **플러그인** (Plugin): 설치형.
  - **테마** (Theme): 비실행형. 스타일의 묶음.
  - **모듈** (Module): 실행형. 스크립트의 묶음.
- **패키지** (Package): 설치형.
  - **애플리케이션** (Application): 샌드박스. Store에서 판매되는 패키지의 기본 및 권장값.
  - **프로그램** (Program): 비샌드박스. Store에서 등록, 혹은 감사 후 배포 가능.

**유통 방식**:

- **Store**: 수익 창출 가능. 수수료 존재. 프로그램 배포 시 등록되지 않았다면 매 업데이트마다 감사가 필수. 클로즈드 소스가 기본값이며, 소통과 문화가 유지되는 대신 무단 복제 등에 대한 위험도가 높아지는 오픈 소스는 개발자의 선택.
- **외부 유통**: 유료 패키지 판매와 유료 추가 기능을 통한 직접적인 수익 창출 금지 (후원 및 기부 등은 허용). 외부 유통자는 수수료 청구 금지. 등록, 혹은 감사 없음. Store 패키지에 대한 무단 복제 및 지적 재산권 침해는 지속될 시 집단 소송 형태의 법적 대응으로 이어질 수 있음을 명시.
